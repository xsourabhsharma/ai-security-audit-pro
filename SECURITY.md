# Security Policy

## Supported Versions

Security Audit Pro is pre-1.0. Security fixes are accepted for the latest version on the default branch.

## Reporting A Vulnerability

Please report security issues privately to the repository maintainer.

Do not include live secrets, credentials, tokens, cookies, or private customer data in reports. Redact sensitive values and provide only the minimum evidence needed to reproduce.

## Responsible Use

This project is for authorized defensive security work. Users are responsible for obtaining permission before scanning hosted systems and for following all applicable laws, rules of engagement, and disclosure policies.
